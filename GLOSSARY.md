# Запись на звонок

Словарь сервиса, в котором гость бронирует время для звонка с одним заранее заданным владельцем календаря.

## Термины

**Владелец календаря**: человек, чьё доступное время публикуется для записи и с кем проводится встреча.

**Гость**: человек, который без регистрации выбирает время и записывается на звонок с владельцем календаря.

**Тип встречи**: вариант встречи с названием, описанием и длительностью, который гость выбирает перед поиском времени.
_Не использовать вместо_: тип события.

**Каталог типов встреч**: первый экран гостевого пути записи, на котором гость выбирает тип встречи перед просмотром календаря.

**Запись**: подтверждённое бронирование гостем времени для встречи определённого типа.

**Встреча**: запланированный звонок гостя с владельцем календаря, соответствующий записи.
