# Итоги интервью: главная страница

Главная — публичный вход для гостя в сервис записи на звонок. Ориентир по структуре — `01-home.png` из задания: шапка, основной блок с коротким описанием, кнопка «Записаться» и карточка «Возможности». Тексты — на русском языке. В шапке используется название «Календарь звонков», основной заголовок — «Запись на звонок».

- Кнопки «Записаться» в шапке и основном блоке ведут на `/book`.
- Карточка «Возможности» описывает будущий сценарий и явно помечена «Скоро»; она не выдаёт функции бронирования за уже работающие.
- Ссылка «Админка» пока отсутствует.
- `/book` — будущий каталог типов встреч. Сейчас там заголовок «Каталог типов встреч», сообщение «Запись пока недоступна» и ссылка на главную; вымышленных типов встреч и слотов нет.

Проверка через публичный HTTP-интерфейс: главная отвечает успешно и содержит рабочую ссылку на `/book`; `/book` отвечает успешно и предлагает вернуться на главную.
