# PostgreSQL защищает интервалы записей

Записи хранятся в PostgreSQL, а ограничение исключения запрещает пересекающиеся полуоткрытые интервалы `[начало, конец)` на уровне базы данных. Это обеспечивает атомарную защиту для одновременных запросов независимо от типа встречи и разрешает примыкание интервалов; сохранность после перезапуска контейнера не является обещанием продукта.
