# Стабильный вход в запись через каталог

Кнопки «Записаться» на главной ведут на `/book` — адрес каталога типов встреч. Пока каталога нет, по тому же адресу показываем явную заглушку. Так гостевой путь и ссылки на него сохранятся при появлении бронирования; скрывать переход до готовности каталога не будем.
