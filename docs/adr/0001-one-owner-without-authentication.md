# Один владелец без авторизации

Сервис рассчитан на одного заранее заданного владельца календаря и гостей без регистрации. Авторизацию и личные кабинеты не вводим, чтобы сосредоточиться на выборе свободного времени и защите от пересечений записей. Это осознанное ограничение учебной версии: управление типами встреч не разграничивается по пользователям.
