# Не раскрывать email гостя в публичном списке

В приложении нет авторизации, поэтому список предстоящих встреч и его API доступны любому посетителю. При создании записи гость указывает имя и email, но список владельца возвращает только имя, тип встречи и время; email остаётся в записи и ответе на её создание. Так контактные данные не публикуются, хотя владелец пока не сможет получить email из интерфейса без отдельного защищённого доступа.
